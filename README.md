# 중국어 탐험대 · 대나무 언덕 2차시 (약 5분)

1차시 「대나무 언덕의 비밀」에 이어지는 2차시 복습 게임입니다. 같은 판다·종·통통 버섯이 나오고, 마지막에 언덕 중간의 **대나무 괴물**이 길을 막습니다.

| 순서 | 장소 | 내용 (PPT 쪽수) |
| --- | --- | --- |
| 1 | 몸 노래 종 | 头·肩膀·膝盖·脚 듣고 판다 몸 짚기 (2, 4쪽) |
| 2 | 얼굴 노래 종 | 眼睛·耳朵·嘴·鼻子 듣고 얼굴 짚기 (3쪽) |
| 3 | 연필 종 | 谢谢 → 不客气 (5~6쪽) |
| 4 | 공책 종 | 对不起 → 没关系 (7~8쪽) |
| 5 | 해와 달 종 | 早上好·晚安·明天见을 상황 그림에 놓기 (10~17쪽) |
| 보스 | 대나무 괴물 | 인사말 탐정 O/X 3문제 (20~25쪽) |

## GitHub에 올리기
1차시와 **다른 저장소**에 올려야 1차시 게임이 그대로 남습니다. (예: 새 저장소 `panda-lesson2`)
- index.html, style.css, game.js — 게임 (고치지 않아도 됨)
- game-data.js — **선생님이 고치는 파일** (문제, 괴물 대사, 점수, 음성)
- sound-check.html — 휴대폰 소리 점검
- audio-list.html — 음성 파일 목록과 저장 방법
- audio/ — 녹음 MP3를 넣는 폴더

## 점수
- 종 문제: 처음 100, 다시 맞히면 60
- 대나무 괴물: 3문제를 한 번도 안 틀리면 150, 틀린 적이 있으면 90
- 별 +10, 버섯 밟기 +20(버섯마다 한 번), 버섯과 부딪히면 −10 (학습 점수는 줄지 않음)
- 결과는 아직 학생 기기에만 저장됩니다.
